# plugin/ — исторический standalone Sender

**Неактивен в основном релизе v0.1.** Корневой CMake собирает `fender/Source` как один универсальный `DAW Streamer.vst3`, который работает в режимах Sender и Master Recorder. Этот каталог сохранён для истории первоначальной standalone-архитектуры; не вносить здесь исправления #34 вместо действующей цели.

См. [актуальную архитектуру](../docs/architecture.md), [передачу разработки](../docs/current-handoff.md), [основной CMake](../CMakeLists.txt).
