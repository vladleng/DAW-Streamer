# VST3-плагин

Здесь будет исходный код отправителя аудио и его интерфейса. Сейчас реализации нет.

Плагин должен пропускать аудио без изменений, передавать копию рекордеру и показывать состояние подключения и записи. Ошибки отправки не должны блокировать живое звучание.

См. [архитектуру](../docs/architecture.md).
