# Требования DAW Streamer

Статус: начальные требования; программная реализация отсутствует.

## Назначение и сценарий

Записывать выступление из Show Page через собственные VST3-плагины в отдельный рекордер на том же компьютере, без Reaper.

- Вокал и гитара: точку отправки размещать до обработки, которую не требуется записывать.
- Клавиши: записывать аудио с выхода виртуального инструмента.
- Каждый экземпляр отправляет сигнал своей точки включения; плагин не получает автоматически доступ ко всем каналам микшера.
- Живое звучание имеет приоритет над записью.

## Первый прототип

1. Один экземпляр плагина принимает аудио и пропускает его без изменений.
2. Копия аудио передаётся отдельному процессу через общую память.
3. Рекордер сохраняет один WAV и корректно завершает файл при Stop.
4. Отсутствие или остановка рекордера не блокирует обработку аудио в DAW.
5. Потери данных обнаруживаются и отображаются, а не скрываются.

Критерий готовности: тестовый сигнал из Show Page записан без пропусков, перестановок блоков и непредусмотренного изменения отсчётов в выбранном формате.

## Целевая первая рабочая версия

- Несколько экземпляров плагина, моно- и стереопотоки.
- Отдельный WAV для каждого потока, понятные имена каналов, общая папка сессии.
- Общие Record/Stop с возможностью управления из любого экземпляра плагина.
- Согласованная временная шкала дорожек; пропуск не должен сдвигать последующий материал.
- Отображение подключения, записи, сигнала и ошибок.
- Сохранение настроек и инструкция по установке.
- Запись должна учитывать остановку транспорта и переключение песен Show Page; фактическое поведение хоста необходимо исследовать до обещания непрерывности.

## Надёжность

- Не выполнять дисковую запись, ожидание рекордера и блокирующие операции в аудиопотоке.
- Использовать ограниченные заранее подготовленные буферы.
- Контролировать переполнение, несовместимость протокола и изменение формата аудио.
- Не перезаписывать существующие записи без явного действия пользователя.
- Проверить длительную запись, заполнение диска и аварийное завершение.
- Предусмотреть стратегию файлов больше 4 ГБ: RF64 либо разделение на сегменты; выбрать до длительных испытаний.
- Определить границы восстановления после сбоя и проверить их экспериментально.

## Предложения, требующие технического решения

- Первая платформа: Windows x64.
- Формат записи: рассмотреть WAV 32-bit float; окончательный выбор зафиксировать перед прототипом.
- Поддерживаемые частоты дискретизации, размеры блоков, число потоков и допустимая нагрузка.
- Версия Show Page и поведение обработки при неактивных каналах, bypass и смене песен.
- Источник общей временной шкалы и поведение при разрывах.
- Средства разработки, зависимости и условия их использования.

## За пределами первого прототипа

Сетевая передача на другой компьютер, MIDI-запись, маркеры и экспорт проектов. Эти функции не входят в текущие обязательства первой версии.
