# Этап 2 — проверка Fender Studio Show Page

Целевой хост: Fender Studio 8.1.2 (113407), Windows 11 x64, 48 kHz, buffer 128 samples.

Этот документ заполняется по результатам проверки минимального pass-through VST3 в реальном Show Page. На Этапе 2 shared memory и запись WAV ещё не участвуют.

## 1. Загрузка и прозрачность сигнала

- [x] `DAW Streamer.vst3` обнаруживается Fender Studio.
- [ ] Плагин загружается на моно-канал.
- [ ] Плагин загружается на стерео-канал.
- [x] При слуховом A/B на проверенном канале включение/выключение `DAW Streamer` не даёт слышимого изменения сигнала.
- [x] При проведённой проверке нет слышимых щелчков или dropout с buffer 128.

Результат первой ручной проверки: пользователь подтвердил, что плагин загружается в Fender Studio 8.1.2 (113407), Recorder запускается отдельно, а со звуком при A/B всё в порядке. Точные mono/stereo проверки остаются отдельными пунктами, чтобы не считать их выполненными без явного подтверждения.

## 3. Временные данные хоста

Проверить данные, доступные через `AudioPlayHead::getPosition()`:

- `getIsPlaying()`;
- `getTimeInSamples()`;
- `getPpqPosition()`;
- `getBpm()`;
- `getTimeSignature()`;
- `getLoopPoints()` / looping, если Show Page их предоставляет.

Для каждого поля зафиксировать:

1. доступно ли оно вообще;
2. меняется ли при Stop;
3. сбрасывается ли при переключении песни;
4. одинаково ли ведёт себя в разных экземплярах плагина.

## Критерий завершения Этапа 2

Этап завершён, когда:

- VST3 успешно загружается в целевом Show Page и прозрачно пропускает mono/stereo signal;
- вручную проверены Stop, bypass, неактивный канал и переключение песни;
- зафиксирован фактический набор временных данных хоста и ограничения, важные для общей временной шкалы будущей записи.
