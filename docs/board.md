# DAW Streamer — доска разработки

Это доска в Markdown со ссылками на GitHub Issues; она не является нативным GitHub Project и не поддерживает перетаскивание. Статусы таблицы обновляются вручную при изменении этапа, чек-листы — в Issues.

## Решения версии 0.1

Аудио до обработок; клавиши после инструмента до эффектов. Ручной запуск, Record/Stop в рекордере. Каждое отделение 40–50 минут — новый дубль. Шаблоны разных Show включены. MIDI позже.

## Правила

- Начинать со следующей задачи; после начала менять статус на «В работе».
- В «Проверку» переносить только при выполнении чек-листа; закрывать Issue после подтверждения результата.
- Блокировки записывать в задаче вместе с требуемым решением.
- Новые идеи создавать отдельными Issues с префиксом «Идея»; включать в релиз только после выбора объёма.
- Сейчас задач в работе нет; реализация не начата.

## Перенос в GitHub Projects

Нативный Project ещё не создан: текущее подключение не предоставляет операций Projects. В интерфейсе GitHub создать проект DAW Streamer с видом Board, добавить Issues #1–#11 из репозитория и использовать статусы «Идеи», «Запланировано», «В работе», «Проверка», «Готово». Первой выбрать #1; #9–#11 оставить в идеях. После переноса сделать Projects источником статусов, а эту страницу — указателем на проект.
