# Проверки

Здесь будут автоматические проверки; сейчас тестовый код отсутствует.

Планируемые области:

- Передача: целостность отсчётов, порядок блоков, переполнение и переподключение.
- Синхронизация: импульсы нескольких потоков, позднее подключение и сохранение временных разрывов.
- Файлы: заголовки WAV, длительность, число каналов, закрытие и большие файлы.
- Надёжность: недоступность рекордера, ошибка диска и аварийное завершение.

Проверки в реальной Show Page выполняются отдельно: остановка транспорта, смена песен, bypass и длительный прогон. Результаты должны включать версии ОС/DAW и параметры аудио.
