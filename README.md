# DAW Streamer

DAW Streamer появился из конкретной практической проблемы: в Studio One / Fender Studio в режиме Show Page нельзя штатно записать полноценное многодорожечное выступление так, как это делается в обычном DAW-проекте. Для live-работы это неудобно: чтобы получить отдельные дорожки после концерта, приходится запускать вторую DAW, строить дополнительную маршрутизацию или использовать внешние решения вроде ReaStream.

Такая проблема не обязательно уникальна для Show Page. Многие программы, ориентированные прежде всего на live performance, могут хорошо решать задачу исполнения, переключения песен, патчей и управления сценой, но при этом иметь ограниченные возможности записи отдельных сигналов или выбранных точек внутри аудиоцепи.

Именно для таких сценариев и создаётся DAW Streamer: VST3 sender-плагин и отдельное приложение Recorder позволяют «вытащить» аудио из нужных точек live-host/DAW и записать несколько синхронных потоков без запуска второй DAW только ради записи.

Sender прозрачно пропускает звук дальше и одновременно передаёт его копию в отдельный Recorder на том же Windows-компьютере. Один из sender-инстансов может дополнительно принимать MIDI от host routing и передавать его в Recorder вместе с аудио.

## Текущая версия

**v0.3.0 — стабильная рабочая версия для Windows x64 с синхронной записью аудио и MIDI.**

Основные возможности:

- четыре синхронных аудиопотока;
- отдельные 24-bit PCM WAV при 48 kHz;
- прозрачный audio pass-through;
- общая временная шкала записи, независимая от Play/Stop транспорта хоста;
- Record/Stop из Recorder или любого экземпляра DAW Streamer;
- отображение времени текущей записи `HH:MM:SS`;
- стандартный boolean VST3-параметр `Recording` для назначения на control surface/MIDI-контроллер через возможности хоста;
- двусторонний VST3 parameter feedback, если его поддерживает хост;
- сохранение папки записи и имени session между запусками;
- безопасное создание новых take без перезаписи предыдущих;
- дополнительный MIDI event stream без пятого обязательного audio sender-а;
- экспорт `MIDI.mid` рядом с четырьмя WAV после Stop;
- обычный single-track Standard MIDI File Type 0, 960 PPQ;
- сохранение Note On/Off, velocity, CC, pitch bend, aftertouch и sustain pedal (CC64).

DAW Streamer не использует Fender-specific API. Текущая версия разработана как обычный VST3 и потенциально применима в других Windows VST3-hosts, где нужно получить отдельные аудиопотоки из выбранных точек цепочки и, при наличии подходящей MIDI routing возможности, сохранить MIDI исполнение параллельно с аудио.

## MIDI routing

Проверенная конфигурация использует четыре экземпляра DAW Streamer: `Vocal`, `Guitar`, `Keys`, `Playback`.

Для MIDI отдельный пятый экземпляр не нужен. Служебный MIDI Player в host направляет копию входящего MIDI в тот же экземпляр DAW Streamer, который пишет `Keys` audio. В Recorder MIDI остаётся отдельным логическим event stream и не участвует в условии готовности `4/4 audio streams`.

Итог MIDI-enabled take:

```text
Take_YYYY-MM-DD_HH-MM-SS/
  Vocal.wav
  Guitar.wav
  Keys.wav
  Playback.wav
  MIDI.mid
```

Темпо-карта, BPM и time signature в MIDI-файл не записываются. Версия 0.3.0 ориентирована на сохранение самого исполнения и его последующее редактирование в DAW.

## Проверенная среда

Ручная проверка версии 0.3.0 проводилась в следующей конфигурации:

- Windows 11 x64;
- Fender Studio Pro / Show Page;
- 48 kHz;
- VST3 sender + standalone Recorder;
- четыре аудиопотока + MIDI;
- аппаратное управление через MIDI Captain;
- MIDI routing через отдельный служебный Player в существующий Keys sender;
- импорт `MIDI.mid` обратно в DAW с проверкой соответствия нот аудиодорожке Keys;
- sustain pedal CC64 сохранён и подтверждён после импорта.

Fender Studio здесь является проверенной средой, а не обязательной зависимостью проекта.
