# Причина

Я уже давно использую для живых выступлений Studio One Show Page и меня всегда удивляло отсутствие возможности записать свое выступление, хотя бы мастер трек. Разработчикам много об этом писали, но по непонятной причине эта возможность так и оставалась за бортом. Приходилось придумывать ухищрения, вроде записи в другую DAW, такую как Reaper с использованием плагина ReaStream. Но на живом выступлении мне не хочется заниматься контролем записи в другую DAW, переключаться для запуска записи в другое приложение, проверять включилась ли запись и тд. На выступлении не хочется отвлекаться на подобные вещи. Поэтому было принято решение разработать максимально простой плагин, который бы одной кнопкой начинал запись и показывал бы состояние сервера (рекордера), чтобы не приходилось открывать оно другой DAW или приложения для записи.

# DAW Streamer

DAW Streamer — проект VST3-плагина отправки аудио и отдельного приложения-рекордера для записи выступлений и репетиций из DAW.

Основной сценарий — запись каналов Show Page в отдельные аудиофайлы без Reaper. Плагин должен пропускать звук без изменений и передавать его копию рекордеру на том же компьютере.

## Статус

Подготовлена начальная документация и структура репозитория. Исходный код, сборка и рабочие установочные файлы пока отсутствуют. Описанные возможности — требования к будущей реализации.

Первый технический рубеж: один канал Show Page → плагин → рекордер → WAV.

## Структура

| Путь | Назначение |
| --- | --- |
| plugin/ | VST3-плагин отправки аудио |
| recorder/ | Приём аудио, управление сессией и запись файлов |
| shared/ | Общий протокол и структуры данных |
| tests/ | Проверки передачи, синхронизации и файлов |

В папках пока находятся только описания будущих компонентов.

## Сборка и запуск

Команды сборки и запуска появятся после создания каркаса проекта и выбора инструментов разработки. Первой целевой платформой предлагается Windows x64; основной хост проверки — используемая пользователем версия Show Page.

Необходимые версии ОС, DAW, компилятора и зависимостей будут зафиксированы на этапе подготовки сборки.

## Первая версия и задачи

Долгосрочная цель, описанная в разделе «Причина», — управление записью из плагина. Для версии 0.1 согласовано упрощение: ручной запуск приложения и Record/Stop только в окне рекордера. Каждое отделение 40–50 минут — отдельный дубль, все дорожки до обработок (клавиши после инструмента перед эффектами). Шаблоны разных Show входят в 0.1, MIDI отложен.
