# DAW Streamer

DAW Streamer — VST3-плагин для непрерывной синхронной записи нескольких аудиопотоков и MIDI прямо из live-host/DAW без запуска второй DAW для записи.

Проект создан Moon River Studio и изначально разрабатывался для практической работы в Fender Studio Pro / Studio One Show Page, где важно сохранять отдельные сигналы всего выступления независимо от переключения Songs и Play/Stop транспорта. При этом основная архитектура использует обычный VST3 и Windows shared memory и не требует Fender-specific API.

## Текущая версия

**v0.1 — основной релиз для Windows x64.**

DAW Streamer теперь работает как один VST3 в двух режимах:

- **Sender** — ставится на нужные каналы, прозрачно пропускает сигнал и отправляет копию в общий transport;
- **Master Recorder** — ставится одним постоянным экземпляром на Main/Master, управляет записью и пишет итоговые WAV + MIDI.

Отдельное приложение Recorder для основного workflow больше не требуется.

## Экземпляры и имена

Поддерживаются четыре фиксированных внутренних потока. Пользователь видит их как:

- `Inst 1`
- `Inst 2`
- `Inst 3`
- `Inst 4`

При добавлении Sender свободный slot назначается автоматически. Имя можно сразу изменить в главном окне экземпляра, например на `Vocal`, `Guitar`, `Piano` или `Backing`.

Пользовательские имена сохраняются вместе с проектом/Show, отображаются в Master Recorder и используются в именах готовых WAV. Если имя не менять, итоговые файлы называются `Inst 1.wav`, `Inst 2.wav` и т. д. Имена санитизируются для Windows, а совпадающие названия получают безопасный числовой суффикс.

## Основные возможности

- четыре синхронных audio streams;
- отдельные 24-bit PCM WAV при 48 kHz;
- прозрачный audio pass-through;
- один непрерывный take независимо от Play/Stop транспорта хоста и переключения Songs;
- встроенный Master Recorder внутри VST3;
- Record/Stop из Master или Sender через общий `Recording` VST3 parameter;
- двусторонний parameter feedback, если его поддерживает host;
- компактный рабочий интерфейс с подробной диагностикой в `Details`;
- сохранение папки записи и имени session;
- пользовательские имена Sender-инстансов и итоговых WAV;
- один дополнительный MIDI event stream без отдельного пятого audio sender;
- экспорт `MIDI.mid` рядом с WAV после Stop;
- Standard MIDI File Type 0, one track, 960 PPQ;
- сохранение Note On/Off, velocity, CC, pitch bend, aftertouch, program change и sustain pedal CC64;
- Drop/Gaps/Queue и другие технические счётчики доступны в диагностике, но не перегружают основной экран.

## Типичная схема

```text
Inst 1 Sender ─────┐
Inst 2 Sender ─────┤
Inst 3 Sender ─────┼── shared memory ──→ DAW Streamer Master Recorder
       + MIDI      │
Inst 4 Sender ─────┘
                                      │
                                      ├─ <Instance 1 name>.wav
                                      ├─ <Instance 2 name>.wav
                                      ├─ <Instance 3 name>.wav
                                      ├─ <Instance 4 name>.wav
                                      └─ MIDI.mid
```

Master Recorder не записывает мастер-шину по умолчанию. Он используется как постоянный управляющий и записывающий узел и прозрачно пропускает Main audio.

## MIDI

MIDI может поступать в один из Sender-инстансов параллельно с его audio. Отдельный пятый Sender не нужен. MIDI не участвует в условии готовности `4/4 audio streams` и не блокирует аудиозапись.

DAW Streamer сохраняет само исполнение. Темпо-карта, BPM и time-signature map в `MIDI.mid` не записываются; при необходимости музыкальная сетка задаётся после импорта в целевую DAW.

## Проверенная среда

Релиз v0.1 вручную проверен в:

- Windows 11 x64;
- Fender Studio Pro / Show Page;
- 48 kHz;
- четыре Sender-инстанса + один Master Recorder;
- запись audio + MIDI;
- переключение Songs во время непрерывной записи;
- импорт MIDI обратно в DAW с проверкой синхронности с Keys audio;
- sustain pedal CC64;
- сохранение и восстановление пользовательских имён;
- формирование WAV с пользовательскими именами.

Поведение в других VST3-hosts может зависеть от lifecycle/suspend и MIDI routing конкретного хоста, поэтому другие DAW будут валидироваться отдельно.

## Установка

Релиз содержит один основной плагин:

`DAW Streamer.vst3`

Скопируйте VST3 bundle в стандартную Windows VST3-папку и выполните rescan плагинов в host.

## Версионирование

v0.1 считается первым полноценным релизом новой embedded-recorder архитектуры. Если дальнейшие реальные выступления выявят дефекты, исправления будут выпускаться как v0.1.1, v0.1.2 и далее.
