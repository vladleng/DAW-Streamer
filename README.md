# DAW Streamer

DAW Streamer — VST3 sender-плагин и отдельное приложение Recorder для многодорожечной записи живого выступления или репетиции прямо из live-host/DAW без запуска второй DAW только ради записи.

Sender прозрачно пропускает звук дальше и одновременно передаёт его копию в отдельный Recorder на том же Windows-компьютере. Его можно поставить в нужную точку цепочки и получить отдельные синхронные WAV для последующей обработки.

Проект появился из практической live-задачи: не отвлекаться на вторую DAW, дополнительную маршрутизацию и отдельный контроль записи во время выступления.

## Текущая версия

**v0.2.0 — готовая протестированная версия для Windows x64.**

Основные возможности:

- четыре синхронных аудиопотока;
- отдельные 24-bit PCM WAV при 48 kHz;
- прозрачный audio pass-through;
- общая временная шкала записи, независимая от Play/Stop транспорта хоста;
- Record/Stop из Recorder или любого экземпляра DAW Streamer;
- отображение времени текущей записи `HH:MM:SS`;
- стандартный boolean VST3-параметр `Recording` для назначения на control surface/MIDI-контроллер через возможности хоста;
- двусторонний VST3 parameter feedback, если его поддерживает хост;
- сохранение папки записи и имени session между запусками;
- безопасное создание новых take без перезаписи предыдущих.

DAW Streamer не использует Fender-specific API. Текущая версия разработана как обычный VST3 и потенциально применима в других Windows VST3-hosts, где нужно получить отдельные аудиопотоки из выбранных точек цепочки. Совместимость и возможности parameter mapping зависят от конкретного хоста.

## Проверенная среда

Полная ручная проверка версии 0.2.0 проводилась в следующей конфигурации:

- Windows 11 x64;
- Fender Studio Pro / Show Page;
- 48 kHz;
- VST3 sender + standalone Recorder;
- четыре длительных/обычных потока;
- аппаратное управление через MIDI Captain.

Fender Studio здесь является проверенной средой, а не обязательной зависимостью проекта.

## Что нового в v0.2.0

Версия 0.2 добавила две функции поверх стабильного аудиоядра 0.1:

1. **Recording time** — Recorder и все экземпляры VST3 показывают одну фактическую длительность текущего дубля в формате `HH:MM:SS`.
2. **Host control** — DAW Streamer публикует boolean VST3-параметр `Recording` (`OFF = Stop`, `ON = Record`). Совместимый хост может назначить его на кнопку/control surface и, при поддержке обратной связи, отражать фактическое состояние Recorder.

Recorder остаётся authoritative state: если запись запущена из standalone Recorder или другого экземпляра DAW Streamer, состояние синхронизируется обратно во все sender-плагины и доступные host controls.

## Установка

В релизном архиве находятся:

- `DAW Streamer.vst3` — sender-плагин;
- `DAW Streamer Recorder.exe` — standalone Recorder.

Скопируйте VST3 в стандартную пользовательскую или системную папку VST3 Windows и выполните пересканирование плагинов в вашем хосте. Recorder можно хранить в любой удобной папке и запускать вручную перед репетицией или выступлением.

## Размещение sender

Sender ставится в той точке цепочки, сигнал из которой вы хотите записать.

В тестовой конфигурации использовались четыре роли:

- **Vocal** — до обработки;
- **Guitar** — до обработки;
- **Keys** — после виртуального инструмента, но до эффектов;
- **Playback** — до обработки.

Это названия текущих четырёх stream slots, а не обязательные типы инструментов. Пользовательские имена потоков запланированы для версии **0.2.1** (#25).

Одна внутренняя роль/slot должна быть занята только одним активным sender-инстансом.

## Запись

1. Запустите `DAW Streamer Recorder.exe`.
2. Выберите базовую папку записи и укажите имя session.
3. Откройте ваш live-host/DAW и убедитесь, что нужные sender-инстансы активны.
4. Запустите запись кнопкой Record в Recorder, в VST3 или mapped-кнопкой `Recording`, если хост поддерживает назначение VST3-параметров.
5. Stop закрывает текущий take. Следующий Record создаёт новый take и не перезаписывает предыдущий.

Структура результата в v0.2.0:

```text
Recording folder/
└── Session/
    └── Take_YYYY-MM-DD_HH-MM-SS/
        ├── Vocal.wav
        ├── Guitar.wav
        ├── Keys.wav
        └── Playback.wav
```

Все четыре файла сохраняют общую временную шкалу. При временном исчезновении sender callback Recorder сохраняет timeline, вставляя соответствующий участок тишины, а не сжимая время.

## Host control и MIDI

DAW Streamer публикует стандартный VST3-параметр **`Recording`**.

В проверенной конфигурации он был назначен на Fender Studio Performance Mode и далее на MIDI Captain. Полная двусторонняя цепочка Record/Stop и LED/state feedback прошла проверку.

Это подтверждает работу механизма через стандартный VST3 parameter feedback; другие хосты могут предоставлять собственные способы mapping и control-surface feedback.

## Ограничения v0.2.0

- только Windows x64;
- проверенный формат текущего live-сценария — 48 kHz;
- четыре фиксированных stream slots;
- пользовательские имена потоков появятся в v0.2.1;
- MIDI performance capture пока не реализован;
- автоматический запуск записи намеренно отсутствует;
- recovery после аварийного завершения будет разрабатываться только при появлении реального проблемного сценария;
- шаблоны разных конфигураций отложены на поздний этап;
- визуальный интерфейс пока технический и будет переработан в версии 0.3.
